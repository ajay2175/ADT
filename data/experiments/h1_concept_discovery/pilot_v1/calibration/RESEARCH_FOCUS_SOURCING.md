# Candidate research situations (sourcing guide)

**Not pre-labels for observations.** Use during curation to diversify **ground_truth** planning after passages are verified.

| Focus | What to look for in sources |
|-------|----------------------------|
| Guṇa–Karma | Similar guṇa, divergent karma |
| Sāmānya–Viśeṣa | Shared class, distinct behavior |
| Prabhāva | Effect not reducible to listed guṇa/karma |
| Saṃskāra | Processing changes properties/effects |
| Saṃyoga | Combination alters effect |
| Mātrā | Dose-dependent karma |
| Deśa/Kāla | Context-dependent behavior |
| Anupāna | Vehicle modifies effect |
| Vipāka | Post-digestive transformation |
| Tantrayukti | Inference beyond explicit statement |

Populate `observation_data/` from passages first; assign `research_focus_candidates` in `ground_truth/` only after expert review.
